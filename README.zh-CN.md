带着上下文写，而不是绕着上下文写。墨伴把对话、写作工具和改动审阅放在正文旁边，每一处改动都
先摆出来，落不落到正文由你说了算。

| | |
|---|---|
| **提问** | 选中一段文字直接问，正文不会被动。 |
| **改写** | 写作动作生成候选文本；改动先看清楚——中文以逐字级 diff 呈现——再决定是否应用。 |
| **由你掌控** | 生成期间原文动过的改写会被拒绝，而不是贴到错误的位置；已应用的改动只在目标区间仍然安全时才允许撤销。 |

## 怎么用

1. 从稿件出发——选中一段，或者就在当前笔记里开始。
2. 提一个问题，或者运行一个写作动作。
3. 看结果。你不应用，正文就不会变。

## 上下文按需选择

每个对话各自决定 AI 能看到多少稿件。这是墨伴自己的设置，和模型的思考强度是两回事。

| 模式 | AI 依据什么工作 |
|---|---|
| **Auto** | 交给 Agent 判断：就地综合、在有限的读取范围内检索稿件，或者在正确性确实需要时请求全覆盖。 |
| **Full** | 整部稿件。 |
| **Low** | 只看选区、它的上下文和当前笔记，绝不涉及其他文件。 |

不论哪种模式，哪些库内容可用、实际去读、预算与中断都由墨伴自己把关。连接拿不到路径、拿不到文件
系统能力，也碰不到你的库。

## AI 由你选

在**设置 → 墨伴 → AI Connections** 里添加连接，每个对话各选一个。

选一个服务商，填入密钥，再选模型。墨伴可以连接常用的 AI 服务商，也可以连接任意 OpenAI 兼容端点：

- **服务商** — OpenAI、Anthropic、Google、DeepSeek、OpenRouter、Mistral、Groq、Cerebras、
  Together AI、Fireworks AI、Perplexity、Hugging Face 和 SiliconFlow，各自使用你自己的密钥。
- **Ollama** — 运行在你自己机器上的模型。墨伴不会启动或管理模型进程。
- **自定义 OpenAI 兼容端点** — 自己填写 Base URL，需要时再填密钥。端点可以在本机、局域网、远程或
  自托管环境中；墨伴不要求某一种特定后端。

## 指令与技能

- **项目指令** — `WritingBuddy/instructions/project.md`，用你自己的话写下全书通用的要求。
- **内置技能** — 八个写作任务随插件提供，保持只读；可以在任意一个之上叠加自定义，也可以随时重置。
- **自建技能** — 自己写，和你的自定义一起存放在库里。

指令和技能只会叠加在内置规则之上，不能获得编辑权限，也不能把正文内容变成命令。详见
[Writing skills](docs/SKILLS.md)。

## 隐私与你的数据

- **没有墨伴账号。** 服务商或端点由你自己选择，并遵循它们各自的条款。
- **项目数据留在库里。** 对话、指令和技能都是 `WritingBuddy/` 下的普通文件。
- **凭据只存在这台设备上。** API 密钥和连接凭据不会写进会同步的库文件。
- **没有遥测和分析。**
- **离开库的只有这些：** 发送一轮对话时，选中的正文、你的指令，以及在所选模式下整理出的上下文会发给
  这个对话的连接——除此之外没有别的，不发送时也没有任何东西离开。服务商或端点运营方各自有隐私与
  数据政策。

## 快速开始

1. 在 Obsidian 里打开**设置 → 第三方插件 → 浏览**，搜索 **Writing Buddy**，点**安装**。
2. 在**第三方插件 → 已安装插件**里启用 **Writing Buddy**。
3. 到**设置 → 墨伴 → AI Connections** 添加一个连接。

更新和其他插件一样，通过第三方插件机制送达。

## 要求

Obsidian 1.4.5 或更高，桌面端和移动端均可使用。移动端请使用设备能够访问到的服务商或端点；如果某个
模型服务只监听另一台机器自己的回环地址，移动设备无法访问它。
